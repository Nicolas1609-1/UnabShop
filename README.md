# 🛍️ UNAB Shop



Bienvenido a **UNAB Shop**, la tienda virtual oficial de la Universidad Autónoma de Bucaramanga. Aquí encontrarás productos que reflejan el espíritu y la identidad UNAB, ideales para estudiantes, egresados, docentes y toda la comunidad universitaria.

## 🎓 ¿Qué puedes encontrar?

- Ropa y accesorios con la marca UNAB
- Artículos de oficina y papelería
- Tecnología y gadgets
- Productos de la línea médica
- Termos, mugs y souvenirs
- Libros y útiles escolares

Todos los productos están diseñados para fomentar el sentido de pertenencia y fortalecer los lazos con nuestra comunidad.
